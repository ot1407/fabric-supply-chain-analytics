# Supply Chain Analytics Platform

## Project Overview

This project demonstrates an end-to-end Supply Chain Analytics solution built using Microsoft Fabric.

The goal is to simulate a real company's data platform by implementing the Medallion Architecture (Bronze, Silver and Gold), transforming raw operational data into business-ready insights.

### Technologies

- Microsoft Fabric
- Lakehouse
- Data Factory Pipelines
- SQL
- Data Warehouse
- Power BI
- Star Schema
